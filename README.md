# functional-errors-supplementary-material

This repo contains supplementary material for a PhD thesis.

## Contents

### Feedback Shield
This directory contains the Arduino code that drives the Feedback Shield. Each iteration can be accessed alongside testing code and future experiments.


### Feedback Shield Schematics
The latest schematic and board designs for the Feedback Shield can be located here. This is iteration two's designs.


### Results
The raw data, cleaned tables, statistical analysis and survey imagery can be accessed here.

### Sculpting Code
This is the code for the sculpting code web application. It is the latest version but older commits and versions can be located in the original [repo](https://github.com/j3nsykes/sculpting-code)

### Study Learning Resources
The custom websites built for the studies can be located here and run locally if required.

### Video Links
Video documentation of the Sculpting Code iterations are on Vimeo. The links to which are stored here.
